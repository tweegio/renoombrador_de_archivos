# renoombrador_de_archivos
Renombrador de Archivos con Prefijo (Flask Web App)
Aplicación web desarrollada con **Python + Flask** que permite **renombrar múltiples archivos agregando un prefijo personalizado**, directamente desde el navegador.  
La app procesa los archivos de forma temporal y devuelve un **archivo ZIP** con los archivos renombrados.

Proyecto preparado para **deploy en Vercel** como función serverless.

---

## 🚀 Funcionalidades

- Subida múltiple de archivos
- Definición de prefijo personalizado
- Renombrado automático de archivos
- Descarga en un solo archivo `.zip`
- No requiere instalación local para el usuario final

---

## 🧱 Tecnologías utilizadas

- Python 3
- Flask
- HTML
- Vercel (Serverless Functions)
- GitHub
